# 隐私说明

工具不运营账号服务器，也不会向项目维护者上传账号、配置、日志或游戏记录。

## 本地处理的数据

- 在雷神客户端内读取当前账号、计费状态、剩余时长和加速游戏，用于决定是否需要等待及暂停。
- 从雷神资料和本机进程查询取得游戏进程名，支持按游戏保存手动配置。
- 等待时间、开关和手动进程保存在客户端本地存储中。
- 本地事件日志包含工具版本、状态变化、游戏 ID、等待时间及结果类别；安装记录包含客户端位置、文件指纹和入口备份。不会把账号密码或会话 Token 写入工具日志。

## 网络请求

常规暂停由已登录的官方客户端命令完成，游戏资料查询也使用客户端现有能力。更新功能只请求发布清单和安装包，不附加雷神账号凭据；托管下载的平台会接收正常网络连接信息。

实验性关机保护默认关闭。开启后，会在本地内存中取得当前会话凭据，通过标准输入交给系统 `curl`，向固定官方 HTTPS 暂停地址请求暂停；不把凭据写进配置或命令参数。

## 反馈问题

维护者不会自动收到本地日志或配置。提交 Issue 或截图前，请遮住账号、手机号、余额和安装路径中的个人信息；不要直接上传完整用户目录、配置或原始日志。
