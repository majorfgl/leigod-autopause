在自动暂停设置面板的标题旁显示当前加载的插件版本，方便排查和反馈问题。

版本号与安装管理器使用同一份配置，后续升级时自动更新。

下载 ZIP 并完整解压后运行“雷神自动暂停.exe”安装，或者在已有版本的“更新与修复”中检查稳定版更新。预发布版本需要手动下载安装。

### 验证记录

已在 Windows 64 位系统、雷神 11.3.3.2 的 32 位客户端验证从 v0.5.0 自动升级：旧版后台下载并校验更新包，客户端运行期间保持原版本，正常退出后自动安装 v0.5.1。

新版加载后，设置面板正确显示版本号，原有监控设置保留；再次测试自动暂停后，刷新确认账号已暂停且剩余时长不再减少。安装文件与签名包一致，官方 ASAR、渲染资源和原生二进制未变化。
