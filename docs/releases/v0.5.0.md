雷神自动暂停的首个公开预发布版本，用于试用和反馈。

### 功能

- 在雷神顶部直接设置自动暂停，共用客户端当前登录。
- 游戏退出等待与首次启动等待独立设置，重新进入游戏取消倒计时。
- 自动读取游戏进程，支持手动覆盖与 Windows 备用检测。
- 暂停后复核账号状态和剩余时长，支持正常退出前尝试暂停。
- 客户端更新后尝试恢复插件，支持更新包校验及失败回退。

### 安装

下载 `leigod-autopause-v0.5.0.zip`，完整解压后运行“雷神自动暂停.exe”，选择“安装 / 修复”。安装前请结束游戏与加速。

设置按钮位于搜索框右侧、剩余时长左侧。新安装默认游戏退出等待 5 分钟、首次启动等待 3 分钟，均可调整。

### 测试范围

此前 v0.4.0 已在 Windows 64 位系统、雷神 11.3.3.2 的 32 位客户端完成实际暂停测试。本版本的具体结果见仓库中的兼容性记录。

预发布版本不进入稳定更新渠道。关机保护仍为实验功能，默认关闭。发现未能暂停时请先手动检查计费，再在 Issues 反馈版本和复现步骤。
