雷神自动暂停的首个公开版本。

### 功能

- 在雷神顶部直接设置自动暂停，共用客户端当前登录。
- 游戏退出等待与首次启动等待独立设置，重新进入游戏取消倒计时。
- 自动读取游戏进程，支持手动覆盖与 Windows 备用检测。
- 暂停后复核账号状态和剩余时长，支持正常退出前尝试暂停。
- 客户端更新后尝试恢复插件，支持更新包校验及失败回退。

### 安装

下载 `leigod-autopause-v0.5.0.zip`，完整解压后运行“雷神自动暂停.exe”，选择“安装 / 修复”。安装前请结束游戏与加速。

设置按钮位于搜索框右侧、剩余时长左侧。新安装默认游戏退出等待 5 分钟、首次启动等待 3 分钟，均可调整。

### 测试范围

本版本已在 Windows 64 位系统、雷神 11.3.3.2 的 32 位客户端完成实机测试：

- 只开启计费、尚未加速游戏时自动暂停。
- PUBG 启动并退出后倒计时暂停；等待途中调整时间也能生效。
- 开启 PUBG 加速但未运行游戏时按首次启动等待暂停。
- 每次暂停后刷新账号状态，确认剩余时长不再减少。

另通过 10 项隔离安装、自动修复与回退测试，以及从 GitHub 下载、校验和安装更新包的隔离测试。具体范围见[兼容性与验证记录](https://github.com/majorfgl/leigod-autopause/blob/main/docs/compatibility.md)。

### 更新与反馈

本版本进入稳定更新渠道，后续稳定版可自动检查更新。雷神自身更新后会尝试恢复插件，但不能保证所有新版都兼容。

关机保护仍为实验功能，默认关闭。发现未能暂停时请先手动检查计费，再在 Issues 反馈版本和复现步骤。
