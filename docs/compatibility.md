## 支持边界

面向 Windows 雷神客户端，不适用于 macOS、Linux 或移动端。游戏通过精确进程名判断，游戏大厅和残留同名进程也会算运行中。

客户端小更新会尝试重新识别资源、入口和界面；框架重构、关键命令或状态语义变化、入口受限时，仍可能需要人工适配。无法确认时停用自动暂停，使用者需手动检查计费。

正常退出保护不能覆盖强杀、崩溃和断电。关机保护为实验功能，默认关闭，尚未完成实际关机验收。
