自动修复中的版本变化与模块搬家是在隔离目录中模拟的，不能视为已验证未来雷神版本。v0.5.0 的在线升级隔离测试使用模拟的较旧安装记录；v0.5.1 已完成真实旧公开版的升级测试。

2026-11-01 的 v0.5.0 → v0.5.1 升级验收使用已安装的 v0.5.0 后台更新器和 GitHub 预发布包，通过本机临时测试源提前接收。确认运行期间不替换安装、正常退出后更新、新版界面和配置保留，以及升级后的代表性计费暂停。测试结束恢复默认稳定更新源；签名文件逐一匹配，官方客户端文件摘要未变。本次没有重复 v0.5.0 的 PUBG 完整启动退出测试，相关结果仍按此前版本记录。

v0.4.0 的实机结果为历史记录。实际关机、强杀、崩溃和断电场景未完成验收。

## 支持边界

面向 Windows 雷神客户端，不适用于 macOS、Linux 或移动端。游戏通过精确进程名判断，游戏大厅和残留同名进程也会算运行中。

客户端小更新会尝试重新识别资源、入口和界面；框架重构、关键命令或状态语义变化、入口受限时，仍可能需要人工适配。无法确认时停用自动暂停，使用者需手动检查计费。

正常退出保护不能覆盖强杀、崩溃和断电。关机保护为实验功能，默认关闭，尚未完成实际关机验收。
