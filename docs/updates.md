# 自动维护与更新

本地维护与联网更新是独立流程。本地维护识别 Electron 资源、程序架构及雷神原生模块元数据，记录当前客户端指纹。客户端更新、插件损坏或入口被覆盖后，等待客户端退出再尝试挂载。运行自检确认状态结构、通信桥、暂停命令及界面位置，未确认前不执行自动计费操作。

联网更新默认从本仓库最新稳定 Release 的 `stable.json` 获取签名清单。清单指定固定版本的安装包 URL、版本、大小与 SHA-256。下载器限制 HTTPS 重定向，只允许同主机同端口，或 GitHub 到指定发布文件 CDN 的跳转，限制次数、大小与超时。

清单签名与包内文件签名均由内置公钥验证。只有高于当前版本的包可进入待安装队列。普通使用者不需要 GitHub 登录或令牌；可能受所在网络对 GitHub 的访问情况影响，网络不可用不会停止本地功能。

安装不会为更新强行重启正在使用的客户端。关闭到托盘不算退出。加载自检失败会按工具版本与当前客户端指纹隔离；优先回退到在当前客户端上有成功记录的旧包，没有适用旧包则撤回挂载并恢复官方入口。

预发布只用于手动测试，不更新稳定清单。稳定包发布后不覆盖同版本内容。正式发布前必须验证真实下载、验签、升级与回退，不能把模拟结构测试当作未来真实客户端兼容证明。

完整性验证不等于破解客户端校验。完全更换框架、关键命令语义改变或入口受到限制时，仍可能需要停止内嵌功能并重新评估实现。
