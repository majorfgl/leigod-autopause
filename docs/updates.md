# 更新与修复

## 当前状态

本地修复和联网更新是独立功能。自动更新只接收稳定版，预发布版本需要手动下载安装；没有稳定版可用时，不会把预发布包推送给使用者。版本状态以 [Releases](https://github.com/majorfgl/leigod-autopause/releases) 的标记为准。

## 雷神更新后要做什么

工具会在本地检查插件是否仍可使用，尝试恢复被更新覆盖的入口。客户端完全退出后才处理，之后可以从桌面“雷神自动暂停”入口重新启动。

关闭到托盘不算退出。看到等待退出的提示时，请从雷神菜单正常退出，不需要强行结束进程。

小改动会尽量自动处理；如果新版不兼容，仍可能需要更新工具。按钮没有出现或显示异常时，先手动暂停计费，再打开管理器选择“安装 / 修复”。

## 工具自身如何更新

默认每六小时检查一次稳定渠道；也可以在“更新与修复”中手动检查或关闭自动更新。找到新版后先下载、检查文件，等雷神及游戏退出后再安装。预发布版本不进入稳定渠道。

网络不可用时保留当前版本，已有本地监控继续工作。请从项目 [Releases](https://github.com/majorfgl/leigod-autopause/releases) 获取安装包。

## 更新失败怎么办

无法正常加载时，工具会尝试回退到此前在当前客户端上验证过的版本；没有适用版本时会恢复官方模块入口。此时自动暂停可能不可用，请手动确认计费已暂停。

如果问题持续出现，在 [Issues](https://github.com/majorfgl/leigod-autopause/issues) 中说明工具版本、雷神版本和提示内容。实现细节见 [技术说明](architecture.md)。
