# 技术说明

## 模块分工

| 模块 | 职责 |
| --- | --- |
| C# 管理器 | 定位客户端、安装与卸载、维护任务、下载更新和回退 |
| 插件引导 | 保留官方原生模块导出，附带加载监控代码 |
| 渲染层适配 | 读取账号和当前游戏状态、挂载按钮和设置面板 |
| 监控状态机 | 首次等待、退出等待、重入取消、暂缓及账号切换 |
| 暂停事务 | 动作前复核、调用官方客户端命令、刷新账号并检查结果 |

## 挂载与适配

管理器检查 Electron 资源结构、程序及原生模块的 PE 架构，定位包外模块的元数据入口。安装时备份该入口，将其指向插件引导；引导先加载官方 `.node` 模块并保留原导出，再启动插件。不会覆盖官方 ASAR、原生模块或业务字节码。

当前客户端的资源、模块位置和文件哈希记录为本地指纹，用于发现变化。它不是固定版本白名单。变化后重新定位与备份；入口不唯一或架构不匹配时停止挂载。

加载后确认界面位置、账号和游戏状态结构、通信桥，以及已注册的刷新与暂停命令。探测不会试执行未知计费命令；未确认可用时不启动自动计费操作。

## 监控与暂停

游戏进程名优先采用按游戏保存的手动设置，再读取客户端资料；PUBG 有备用进程名。原生检测不可用时尝试 Windows `tasklist`。运行、退出和查询错误分别处理，查询错误不能触发退出等待。

倒计时使用单调时钟。切换账号、切换游戏、手动暂停、重新进入游戏或修改相关设置会取消或重置旧任务。首次启动等待与退出等待独立配置，仅开启计费但没有游戏目标时也可进入首次等待。

执行前重新读取账号与进程状态。停止加速失败不会直接阻断暂停尝试；调用 `pause-user-time` 后刷新账号，并间隔复核暂停状态和剩余时长是否稳定。有限重试仍未确认时提示失败，不把调用成功等同于计费已停。

## 更新与回退

更新清单提供固定版本安装包 URL、大小及 SHA-256。清单与包内文件清单均通过内置公钥验证，拒绝降级及危险压缩路径。下载只允许 HTTPS，限制大小、超时和跳转次数；跨主机跳转仅允许 GitHub 到指定发布文件 CDN。

客户端和游戏退出后才安装待更新包。新包的兼容判定从下载筛选到安装保持一致，使用结构与运行能力判断。

健康状态绑定工具清单和客户端指纹。失败时优先回退到在同一客户端上有成功记录的版本；没有可用旧版则恢复官方入口。备份和维护副本保存在客户端目录之外。

数据处理范围见 [隐私说明](privacy.md)，实际测试版本见 [兼容性与验证记录](compatibility.md)。模拟目录迁移、版本号变化等测试，用于验证发现和恢复逻辑，不能证明尚未发行的真实客户端兼容性。
